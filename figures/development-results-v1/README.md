# DirectFlow development figures v1

Seven visually reviewed scientific figures are published as editable SVGs.
Verified PNG previews remain in the private postprocessing artifact directory.
The existing publication checker is unchanged. Source identities and result tables
are in [the postprocessing receipt](../../reports/primary-development-postprocessing-v1.json).
Read the [scientific review](../../docs/primary-development-review.md) before
interpreting or sharing these figures.

**Required qualifications:** development data only; protected assessment sealed.
Intervals are conditional, pointwise exploratory estimates, with residual
dependence still present at multi-week lags for Galax. They do not establish
family-wise coverage, interannual uncertainty or calibrated prediction intervals.
Event seed ranges are descriptive, and missing forecasts remain visible.
